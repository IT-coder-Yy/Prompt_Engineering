# API 兼容能力

实现以 OpenAI-compatible Chat Completions 为基线：`POST {Base URL}/chat/completions`，请求含 `model`、`messages`、`temperature` 和 `max_tokens`。优先使用 API 配置页保存在当前浏览器中的连接，未保存时回退到服务器环境变量，再回退到演示模式。

浏览器配置随每次实验请求送到本站转发，不写入服务器文件，不影响其他浏览器。支持 HTTP 和 HTTPS，建议使用 HTTPS；HTTP 会明文传输密钥和输入。页面指定地址只支持公网 API：在实际连接的 DNS 解析阶段验证 IP，并禁止跟随重定向。本地/内网模型仍可通过服务器环境变量配置。

已实现：浏览器配置的保存/恢复/修改/清除、非流式文本响应、环境变量回退、请求长度与参数校验、超时取消、无密钥回显的上游错误提示、可选 usage 展示、无配置演示模式。

使用模拟上游验证配置优先级、请求地址/鉴权/参数以及错误脱敏；组件联动测试验证保存、恢复、修改、清除与两组实验请求，另提供覆盖刷新及页面跳转的浏览器测试用例。未使用真实密钥验证具体供应商、模型和网络环境；流式响应与工具调用不在当前支持范围内。
